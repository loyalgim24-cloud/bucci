# 부찌 (Bucci)
### 9,400개 UI 화면을 말하듯이 찾고, AI가 바로 분석해주는 UIUX 레퍼런스 툴

> **팀 부찌** · 김선진 — (주)솔리데오 크리에이티브 그룹 UIUX디자인팀  
> 2026 해커톤 출품작

---

## 어떤 툴인가요?

"토스처럼 해주세요", "요즘 앱 결제 화면 어떻게 생겼어?", "어르신들도 쓸 수 있게"

이런 말이 나오는 순간은 디자이너만의 이야기가 아닙니다.  
기획자, 개발자, 영업, CS — 누구든 UI 화면이 필요한 순간이 있습니다.

**부찌**는 국내 앱 440개 이상, 화면 9,400개 이상을 한 곳에 모아두고  
전문 지식 없이 말하듯이 검색하면 AI가 바로 찾아주는 레퍼런스 툴입니다.

---

## 주요 기능

| 기능 | 설명 |
|---|---|
| **모아보기** | 국내 앱 440개+, 화면 9,400개+ 한눈에 탐색 |
| **자연어 검색** | "토스 같은", "깔끔한 결제 화면" — 말하듯이 입력하면 AI가 의도 분석 후 탐색 |
| **조합 검색** | "바텀시트가 있는 결제 화면"처럼 여러 조건 동시 적용 |
| **AI 디자인 분석** | 이미지 붙여넣기 → 유사 화면 자동 탐색 |
| **AI UIUX 분석** | 화면 선택 → 주요 컴포넌트·장단점·개선 제안 즉시 생성 |
| **AI KRDS 매핑** | 화면 이미지 → KRDS 컴포넌트 매핑 + 공식 가이드 링크 |
| **컬렉션** | 마음에 드는 화면을 폴더별로 저장·관리 |
| **PC 레퍼런스 직접 등록** | PC 웹 화면도 브랜드별로 등록 → AI 자동 태그 → 동일 검색 체계 |

## 누가 씁니까

| 직군 | 활용 장면 |
|---|---|
| **기획자** | 기능 정의 시 유사 앱 화면 탐색 · 화면 흐름 근거 자료로 활용 |
| **디자이너** | 레퍼런스 수집 · AI UIUX 분석으로 설명 근거 생성 · KRDS 매핑 |
| **개발자** | 구현할 UI 패턴 탐색 · 컴포넌트 구조 참고 |
| **영업·CS** | 고객 상담 중 유사 화면 즉시 제시 |
| **PM·임원** | 회의 중 추상적 요청을 화면으로 바로 구체화 |

## 효과

- 레퍼런스 탐색 시간 **평균 20분 → 5분** (75% 단축) — 직접 측정
- 1인 기준 주 **75분** 절감 — 직접 측정
- 팀 10명 기준 월 **50시간** 절감 — 추정

## 기술 구성

| 구분 | 내용 |
|---|---|
| **앱 프레임워크** | Electron |
| **프론트엔드** | Vanilla JS · HTML · CSS |
| **백엔드** | Node.js |
| **이미지 저장** | Cloudflare R2 |
| **유사 화면 탐색** | Voyage AI (voyage-multimodal-3) |
| **AI 분석·태깅** | Anthropic Claude API (claude-haiku-3) |
| **데이터 수집** | WWIT · UPA · KRDS 연동 자동 크롤링 |
